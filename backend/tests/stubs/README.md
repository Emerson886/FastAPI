"""
离线桩模块说明
==============================================================================

【这个目录是干什么的？】

它提供若干「功能等价的最小实现」，用来替换尚未安装的第三方包，
让你在**没装依赖的情况下也能运行单元测试**，验证项目结构与业务逻辑是否正确。

【什么时候用？】

    # 已安装全部依赖 → 直接用真实包，不需要本目录
    python tests/run_tests.py

    # 尚未安装 loguru / bcrypt / PyJWT / langchain-chroma → 用桩模块跑测试
    python tests/run_tests.py --offline

【桩模块清单】

| 桩文件               | 替换的真实包      | 桩的行为                                        | 保真度 |
|---------------------|------------------|------------------------------------------------|--------|
| `loguru.py`         | loguru           | 所有日志方法都是空操作                            | 低（仅保证不报错） |
| `bcrypt.py`         | bcrypt           | 用 PBKDF2 做真实的哈希/校验，错误密码返回 False    | 中（逻辑等价，非生产级） |
| `jwt.py`            | PyJWT            | encode 返回占位串，decode 一律抛 InvalidTokenError | 低（无法验证令牌往返） |
| `langchain_chroma.py` | langchain-chroma | 空实现，不真正读写向量                            | 低（不涉及向量检索测试） |
| `chromadb.py`       | chromadb         | 内存字典，提供 Collection 基本接口                 | 低（无检索能力） |

【⚠️ 重要提醒】

1. **桩模块绝不能用于生产环境**。它们只保证「接口存在、调用不报错」，
   不具备真实的安全性或功能性。
2. 装了真实依赖后，`--offline` 模式下 sys.path 会把桩目录插到最前面，
   从而**遮蔽真实包** —— 所以正常运行时不要加 `--offline`。
3. 这些桩仅用于「离线自检」。正式开发请务必执行：

       python -m pip install -r requirements.txt
"""
